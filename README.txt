CMS:
The included admin dashboard is CMS-ready. For a secure online CMS that works from multiple devices, create a Supabase project, run supabase-schema.sql, create an admin user, then put the Supabase Project URL and PUBLIC ANON key into config.js. NEVER use a service_role key in browser code.

The next CMS upgrade can add direct photo/video uploads to Supabase Storage, so you choose files in the dashboard instead of first uploading them to GitHub.
